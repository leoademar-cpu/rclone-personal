# rclone personal

Esta página corresponde a una integración personal de rclone con Google Drive.

La aplicación se utiliza únicamente para permitir que el propietario de esta cuenta sincronice archivos entre su computadora Linux y su propia cuenta de Google Drive.

No se ofrece acceso público al servicio ni se utiliza para recopilar datos de terceros.
